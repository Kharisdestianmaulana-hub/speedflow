# SpeedFlow Browser Download Interceptor Extension

Ekstensi resmi browser untuk menghubungkan Google Chrome, Microsoft Edge, Brave, dan browser berbasis Chromium lainnya langsung ke aplikasi desktop **SpeedFlow**.

---

## Cara Memasang Ekstensi (Hanya 10 Detik)

1. Buka browser Anda (Google Chrome, Microsoft Edge, atau Brave).
2. Ketik pada address bar:
   - **Google Chrome / Brave:** `chrome://extensions`
   - **Microsoft Edge:** `edge://extensions`
3. Nyalakan switch **Developer Mode** (Mode Pengembang) di pojok kanan atas.
4. Klik tombol **Load Unpacked** (Muat yang belum dibongkar) di pojok kiri atas.
5. Pilih folder:
   ```
   C:\Users\riray\Documents\SpeedFlow\extension
   ```
6. Selesai! Ekstensi **SpeedFlow Download Interceptor** langsung aktif.

---

## Cara Kerja
1. Pastikan aplikasi desktop **SpeedFlow** sedang berjalan.
2. Saat Anda mengklik link atau tombol unduh di website manapun (file `.zip`, `.iso`, `.exe`, `.mp4`, `.pdf`, dsb.):
   - Ekstensi otomatis membatalkan unduhan bawaan browser yang lambat.
   - Pop-up dialog **Download File Info** dari SpeedFlow langsung otomatis muncul di layar dengan nama file, ukuran, dan opsi percepatan multi-koneksi!
3. Anda cukup klik **Start Download** (atau **Download Later** untuk memasukkan ke antrian).
