# Security Policy

## Supported Versions

SpeedFlow actively maintains and releases security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |
| < 0.1.0 | No                 |

We strongly recommend always running the latest released version of SpeedFlow to receive security and stability updates.

---

## Reporting a Vulnerability

The SpeedFlow team takes the security of our application and users seriously. If you believe you have discovered a security vulnerability in SpeedFlow, please do not disclose it publicly via GitHub Issues or public discussions.

### How to Report Privately:
1. Use GitHub's private vulnerability reporting feature on the repository:
   https://github.com/Kharisdestianmaulana-hub/speedflow/security/advisories/new
2. Alternatively, contact the maintainer directly through GitHub profile contact options.

### Information to Include in Your Report:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the issue (proof of concept code or configuration).
- The operating system and version of SpeedFlow where the vulnerability was observed.
- Any suggested mitigations or patches if available.

### What Happens Next:
- **Acknowledgement:** We will acknowledge receipt of your report within 48 to 72 hours.
- **Assessment:** We will confirm the vulnerability and assess its severity.
- **Resolution:** A fix will be developed and verified across supported environments.
- **Disclosure:** Once the patch is released, a security advisory will be published acknowledging your contribution (unless you prefer to remain anonymous).
